# Mt Zion Secondary School Website

A dynamic PHP and MySQL website developed for Mt Zion Secondary School, Mubende, Uganda.

## 1. Project Overview

The system provides an online platform for presenting school information and managing selected school activities through a database-driven website.

## 2. Technologies Used

- PHP – Server-side programming.
- MySQL – Database management.
- HTML5 – Website structure.
- CSS3 – Website styling.
- JavaScript – Client-side functionality.
- Bootstrap – Responsive interface components.

## 3. Main Website Features

- School information and announcements.
- Admissions information and application submissions.
- News and updates.
- Photo gallery.
- Staff and school administration information.
- Contact and message submission.
- Administrative dashboard for managing website content and submissions.

## 4. Project Structure

The project contains the following main directories:

- `admin/` – Administrative section.
- `assets/` – Website resources such as CSS, JavaScript and images.
- `config/` – Application configuration.
- `database/` – Database-related files.
- `includes/` – Shared application components.
- `seo/` – Search engine optimisation resources.
- `uploads/` – Uploaded website files.

## 5. Installation and Setup

1. Install a local PHP development environment such as WampServer.
2. Copy the project folder into the web server's document directory.
3. Start Apache and MySQL.
4. Create the project database using phpMyAdmin.
5. Import the provided database SQL file.
6. Configure the database connection using the project's configuration file.
7. Open the website through your local browser.

## 6. Version Control

This project is maintained using GitHub for source-code management and collaboration.

The repository uses feature branches and pull requests to manage changes before merging them into the main branch.

## 7. Security and Privacy

Sensitive configuration files, database credentials and confidential school or student information should not be published in the public repository.

## 8. Project Purpose

This project was developed as part of the BIT 2103 Internet Technologies and Advanced Web Development practical examination.
